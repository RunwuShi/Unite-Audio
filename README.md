# Unite-Audio internal Git package

This is the Git-sized internal package. It contains the S2 and S3/RL14 EMA
weights, the spectral and GAN decoder online weights, and the S3/RL14
AudioCaps-886 WAV set. Full resumable checkpoints and the remaining listening
sets remain in the CPFS internal archive.

The 886 captions and WAV ordering are in `evaluation/`.
